# Phone Screenshots

Place your phone screenshots here for the Play Store listing.

## Requirements
- **Dimensions:** 1080 × 1920 pixels (9:16 aspect ratio)
- **Format:** PNG or JPEG
- **Count:** 2–8 screenshots required
- **Min:** 320px, **Max:** 3840px

## Recommended Screenshots (in order)

| # | File Name | What to Capture |
|---|---|---|
| 1 | `01-dashboard.png` | Main dashboard with greeting, KPI cards, quick access grid |
| 2 | `02-quiz-arena.png` | Quiz Arena class selection screen |
| 3 | `03-ai-chat.png` | SmartTutors AI chatbot interface |
| 4 | `04-library.png` | Digital Library with book cards and category tabs |
| 5 | `05-chat.png` | 1-to-1 Chat conversation list or thread |
| 6 | `06-attendance.png` | Attendance tracking view |

## How to Take Screenshots

1. Run the app on a Android device (1080×1920 or similar)
2. Navigate to each screen
3. Take screenshot (Power + Volume Down)
4. Crop to exactly 1080×1920
5. Name them with the numbering above
6. Drop them in this folder

**Tip:** Use `adb shell screencap` for clean captures without status bar.
