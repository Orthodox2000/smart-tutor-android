# Feature Graphic

Place your feature graphic here for the Play Store listing.

## Requirements
- **Dimensions:** 1024 × 500 pixels
- **Format:** PNG or JPEG
- **Used for:** Play Store header banner, Google Ads

## Design Tips
- Include the app name "Smart Tutors" prominently
- Show key visual elements (books, graduation cap, chat bubbles)
- Use brand colors: Orange (#F97316) + Dark Slate (#1E293B)
- Keep text minimal — tagline works best
- Example tagline: "Learn Smarter. Achieve More."
