# Smart Tutors — Google Play Data Safety Questionnaire

This document contains the answers for Google Play's Data Safety section, which must be completed in the Play Console before submission.

---

## Q1: Does your app collect or share any user data?

**Answer:** Yes

---

## Q2: What type of data does your app collect?

**Answer:** The app collects the following categories of user data:

### Personal Information
- Name
- Email address
- Phone number
- Date of birth

### Academic Information
- Grades and test scores
- Attendance records
- Enrollment data (courses, class, section)
- Academic progress and performance data

### Financial Information
- Fee payment history
- Transaction records
- Digital receipt data

### App Activity
- Pages viewed within the app
- Features used and interaction patterns
- Session duration and frequency

### Device Information
- Device model and manufacturer
- Operating system version
- App version number
- Crash logs and diagnostic data

### Location (Approximate)
- Approximate location derived from IP address
- Used solely for analytics and service optimization

---

## Q3: Is all of this data collected or just some of it?

**Answer:** Some of this data is collected. Not all data types listed above are collected from every user. Data collection varies based on user role (student, parent, educator, administrator) and the features they use within the app.

---

## Q4: Does your app share user data with any third parties?

**Answer:** Yes, data is shared with the following third parties for the purposes described below:

| Third Party | Purpose | Data Shared |
|---|---|---|
| **Cloud Hosting Providers** | Secure data storage and retrieval | All stored user data (encrypted at rest) |
| **Analytics Services** | Anonymized usage analytics for app improvement | Anonymized app activity and device info only |
| **Payment Processors** | Fee transaction processing | Financial transaction data only (no personal academic data) |
| **Google Meet** | Live session integration | Session metadata required to join live classes |

**Note:** No user data is sold to third parties. All third-party sharing is limited to what is necessary for the stated purposes and is governed by contractual agreements ensuring data protection.

---

## Q5: What is the purpose of collecting this data?

**Answer:** Data is collected for the following specific purposes:

1. **Account Management and Authentication** — Creating user accounts, verifying identity, and managing login credentials.

2. **Education Service Delivery** — Providing courses, tests, live sessions, attendance tracking, and educational content to students.

3. **Progress Tracking and Analytics** — Generating performance reports, tracking academic progress, and providing insights to students, parents, and educators.

4. **Communication** — Enabling direct messaging, sending notifications (session reminders, fee alerts, test schedules), and facilitating educator-parent-student communication.

5. **Payment Processing** — Processing fee payments, generating digital receipts, and maintaining financial transaction records.

6. **App Improvement and Bug Fixing** — Analyzing anonymized usage patterns and crash data to improve app performance and user experience.

7. **Security and Fraud Prevention** — Detecting unauthorized access, preventing abuse, and ensuring platform integrity.

---

## Q6: Can users request deletion of their data?

**Answer:** Yes. Users can request deletion of their personal data by contacting our support team at **support@smarttutors.co.in**. Upon receiving a verified deletion request, all personal data associated with the user's account will be permanently removed within 30 days, except where retention is required by law.

**Contact for data deletion:** support@smarttutors.co.in

---

## Q7: Is this data encrypted in transit?

**Answer:** Yes. All data transmitted between the app and our servers is encrypted using industry-standard **SSL/TLS encryption**. Data is also encrypted at rest on our servers using AES-256 encryption.

---

## Q8: Do you provide a way for users to opt-out of data collection?

**Answer:** Users can manage their data collection preferences through the following methods:

- **Notification Preferences:** Users can toggle specific notification categories on/off within the app settings.
- **Account Deletion:** Users can request complete account and data deletion by contacting support@smarttutors.co.in.
- **Analytics Opt-Out:** Users can opt out of anonymized analytics collection through in-app settings.

**Note:** Certain data collection is essential for core app functionality (e.g., attendance records, test scores for educational services) and cannot be opted out of while using those specific features.
