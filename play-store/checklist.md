# Smart Tutors — Play Store Pre-Submission Checklist

Use this checklist to ensure everything is ready before submitting to Google Play Console.

---

## Build & Signing

- [ ] `build-playstore.bat` executed to generate AAB file
- [ ] AAB file generated at `app/build/outputs/bundle/release/`
- [ ] AAB is signed with release keystore (NOT debug keystore)
- [ ] Keystore file and credentials stored securely (NOT committed to version control)
- [ ] App versionCode and versionName updated in `build.gradle`
- [ ] Target SDK version matches current Play Store requirements (API 34+)
- [ ] Min SDK version appropriate for target device range

## Store Listing Assets

- [ ] **High-res icon** — 512x512 PNG, round or adaptive icon
- [ ] **Feature Graphic** — 1024x500 PNG (required for tablet and certain placements)
- [ ] **Screenshots** — 2 to 8 screenshots prepared
  - [ ] Phone screenshots (at least 2)
  - [ ] Tablet screenshots (optional but recommended)
  - [ ] Minimum dimension: 320px, Maximum: 3840px
  - [ ] 16:9 or 9:16 aspect ratio
  - [ ] Screenshots demonstrate key features (dashboard, quiz, chat, library, live sessions)

## Store Listing Copy

- [ ] **App Name:** Smart Tutors (13 chars, under 30 limit)
- [ ] **Short Description:** "Smart learning platform for students, educators & parents" (57 chars, under 80 limit)
- [ ] **Full Description:** Written and saved in `store-listing.md` (under 4000 characters)
- [ ] **Full Description** pasted into Play Console (copy from `store-listing.md`)
- [ ] **Release Notes / What's New** written for initial release

## Data Safety

- [ ] Data Safety form completed in Play Console (answers from `data-safety.md`)
- [ ] All data collection types accurately declared
- [ ] All third-party data sharing declared
- [ ] Data deletion process documented
- [ ] Privacy Policy URL entered: `https://smart-tutor-android.vercel.app/privacy-policy`
  - *Note: Privacy Policy is hosted on Vercel. Main website is https://smarttutors.co.in*
- [ ] Privacy Policy is live and accessible

## Content Rating

- [ ] IARC questionnaire completed in Play Console (answers from `content-rating.md`)
- [ ] Rating category confirmed: Everyone / PEGI 3
- [ ] Content rating icon generated by IARC

## Permissions

- [ ] Permissions declared in Play Console (justifications from `permissions-justification.md`)
- [ ] Only 2 permissions declared: `INTERNET`, `ACCESS_NETWORK_STATE`
- [ ] No unnecessary permissions requested
- [ ] Permission declarations reviewed for accuracy

## Testing

- [ ] App tested on physical Android device (not just emulator)
- [ ] All core features verified on device:
  - [ ] Login/Registration flow
  - [ ] Dashboard loads correctly
  - [ ] AI chatbot responds
  - [ ] Quiz Arena functions
  - [ ] Digital Library content loads
  - [ ] Live session joining works
  - [ ] Chat messaging works
  - [ ] Notifications are received
  - [ ] Fee payment flow works
- [ ] App tested on multiple screen sizes (phone + tablet)
- [ ] Offline/online transition tested
- [ ] No crashes or ANRs in release build
- [ ] No memory leaks or performance issues observed

## Google Play Console Setup

- [ ] Google Play Developer account active ($25 one-time fee paid)
- [ ] Developer name and contact info filled in
- [ ] App category selected: **Education**
- [ ] Tags added: education, learning, students, school, quiz
- [ ] Contact details provided:
  - [ ] Email: support@smarttutors.co.in
  - [ ] Phone (optional)
  - [ ] Website: https://smarttutors.co.in
- [ ] Privacy Policy URL: https://smart-tutor-android.vercel.app/privacy-policy
  - *Hosted on Vercel. Main brand site: https://smarttutors.co.in*
- [ ] App access: All users (or specify if restricted)
- [ ] Ads declaration: No ads (if applicable)
- [ ] Content declaration: No objectionable content

## Pricing & Distribution

- [ ] Pricing set: Free (or Paid)
- [ ] Distribution countries selected
- [ ] Device categories: Phone and Tablet (or as applicable)
- [ ] Android TV / Wear OS declared as not applicable (unless relevant)

## Final Review

- [ ] All Play Console sections show green checkmarks
- [ ] No policy violation warnings
- [ ] AAB uploaded to Play Console
- [ ] Release notes entered for the production track
- [ ] Rollout percentage set (recommend starting at 20-50%)
- [ ] Internal/closed testing completed before production release

## Important Notes

1. **Privacy Policy must be live** before submission. Host it at `https://smart-tutor-android.vercel.app/privacy-policy`.
2. **First review** typically takes 3-7 days. Subsequent updates are usually reviewed within 24 hours.
3. **Start with a staged rollout** (20-50%) to monitor for issues before full release.
4. **Keep the release keystore safe** — if you lose it, you cannot update your app.
